Laporan Kerentanan

Detail 2 Kerentanan yang Sengaja Dibuat

Kerentanan 1: Validasi Berkas Lemah (Weak File Upload Validation)

Unrestricted File Upload pada Fitur Unggah Tugas Mahasiswa

Lokasi Fitur: Mahasiswa > Tab "Unggah Tugas".

Mekanisme Masalah: Pemeriksaan berkas tidak membatasi tipe MIME riil di backend dan hanya mengizinkan pengunggahan berkas tanpa validasi ekstensi berbahaya (.html, .php, .js, .svg). Berkas disimpan dan dapat dibuka langsung melalui browser.

Dampak Keamanan: Pengguna jahat dapat mengunggah file HTML bermuatan skrip berbahaya (Stored Web-Deface/Cross-Site Scripting) atau file berbahaya yang jika diklik oleh dosen saat memeriksa tugas akan mengeksekusi skrip di sisi klien.

// Contoh Payload: Mengunggah file 'exploit_tugas.html' dengan konten:
<script>alert('Exploit Validasi Berkas Lemah Berhasil!');</script>
Kerentanan 2: Stored Cross-Site Scripting (Stored XSS)

Injeksi Skrip Tersimpan pada Forum Diskusi Akademik

Lokasi Fitur: Tab "Forum Diskusi".

Mekanisme Masalah: Input pesan atau komentar diskusi disimpan ke database penyimpanan dan ditampilkan kembali ke antarmuka pengguna menggunakan properti berbahaya element.innerHTML tanpa encoding karakter khusus HTML (seperti <, >, ").

Dampak Keamanan: Skrip jahat tersimpan permanen di basis data forum. Setiap mahasiswa atau dosen yang membuka halaman forum diskusi akan secara otomatis mengeksekusi skrip tersebut di browser mereka (pencurian sesi/cookie, deface tampilan, impersonasi aksi pengguna).

// Contoh Payload Stored XSS:
<img src=x onerror="alert('Stored XSS Executed! Session: ' + localStorage.getItem('siakad_active_user'))">
